# fufu 架上替换与独立查看

用已经完成的精修 fufu 替换书桌上方架子上的旧玩偶，床上的精修玩偶保持原位。复用已加载的几何与材质，按旧玩偶占地宽度缩放并保持朝向和架面接触，不重复下载模型。

点击精修 fufu 打开全屏物品查看层；也提供「看看 fufu」按钮供触屏和键盘使用。按照用户补充要求，房间背景保持原来的亮度与色调，不压暗。玩偶居中放大，下方文字严格使用「小鹿送我的fufu ❤️」。

查看层使用独立相机，支持拖动旋转、滚轮和双指缩放、方向键和加减键、复位。返回按钮或 Escape 关闭，保持打开前的房间视角、灯光与屏幕状态。原生 dialog 管理焦点和背景输入隔离，房间渲染在查看时暂停；关闭仅销毁独立渲染器，不释放共享模型资源。

验证架面位置、遮挡与点击判定、拖拽和双指手势不误触、打开关闭后的资源和状态、桌面及手机横竖屏布局。运行测试和构建，保留上一发布版本后更新现有 GitHub Pages，并核对公开资源。
